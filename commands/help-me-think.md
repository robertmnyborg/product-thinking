# Help Me Think

Alias for `/product-thinking:help-me-build` — invoke the `product-thinking` skill.

Open with: **"Tell me in one sentence what you want to build."** (or, if an idea was passed as an argument, treat it as that answer and go into the Why Gate). Then run the skill's arc exactly as in `/product-thinking:help-me-build`: Socratic posture, one question at a time, back off when the answer holds up. Set the build lane in Phase 0: a self-serve automation (author builds and operates it themselves) ends with the Build Sheet via the Self-Serve Build Route; engineering-lane work ends with the Engineering Handoff Inputs block.
